# Shashank's Birthday Gift 💙

Interactive birthday surprise made with HTML, CSS and JavaScript.

## Files
- `index.html`: website content
- `style.css`: responsive pastel styling and animations
- `script.js`: interactive buttons, gifts, candle, letter and heart effects
- `assets/love-bears.svg`: original animated bear-and-panda illustration

Open `index.html` locally, or enable GitHub Pages in Settings → Pages → Deploy from a branch → main → /(root).
